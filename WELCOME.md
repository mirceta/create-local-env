# Welcome 👋

Welcome to **create-local-env** — the tooling that bootstraps a complete local
development environment for the Birokrat stack.

## What lives here

This repository wires together the three layers of the product:

- **Birokrat** — the VB6 desktop application
- **BiroNext Server** — the C# backend
- **BiroNext Web** — the React frontend

Alongside the source, you'll find a PowerShell-based developer environment:
build helpers, git aliases and functions, database and deployment utilities,
and a curated set of `.claude/` skills to keep AI-assisted work on the rails.

## Getting started

- Read [`CLAUDE.md`](CLAUDE.md) for the project conventions (build, git, and
  encoding rules — they matter, especially the Windows-1250 note for VB6 files).
- Browse the concept map under
  [`context/concept-maps/create-local-env.md`](context/concept-maps/create-local-env.md)
  for a guided tour of the environment.
- Explore the skills in [`.claude/skills/`](.claude/skills/) to see what the
  assistant can help with.

Happy hacking! 🚀
